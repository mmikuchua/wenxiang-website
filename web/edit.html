调试入口

选择要编辑的页面

点下面的卡片，会带着 ?edit=1 打开对应页面，左下角出现编辑面板：文字直接改、移动拖动位置、大小拖圆点缩放。改动只存在这台电脑的浏览器里，调完点「导出 JSON」发我，我落进源码。

首页

大标题、副标题、按钮、三张卡片、流程说明、底部面板。

打开编辑 →

问卷

页头、提问框、提示语和按钮可以改；选项文字来自 questions.js，要改得动代码。

打开编辑 →

推荐

页头、一句话搜索框、工具栏和空状态可以改；推荐卡片是动态渲染的，改文案要落到 ui.js。

打开编辑 →

管理端

标题、说明、图表面板标题和操作按钮可以改。

打开编辑 →

三个提醒

必须用网址打开：http://127.0.0.1:8010/edit.html 或线上地址；直接双击 html 文件（file://）浏览器会拦住模块脚本，面板不会出现。

改动只在本机：存在这个浏览器的 localStorage，按页面分开；换浏览器、换电脑就没了，访客也看不到。

调完在面板里点「导出 JSON」，把内容发我——我按 text（文案）、offset（位移）、size（字号/缩放）写进 HTML 和 CSS。

想撤销某个页面的所有改动：面板里点「重置全部」。
